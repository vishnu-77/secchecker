         (v0.3.1 + v0.4.0 hybrid plan)                    STATUS: COMPLETE
================================================================================

NOTE: The hybrid plan reassigned what "v0.4.0" means. It is now the AI/MCP-first
      repositioning below — NOT the incremental-cache/baseline/diff robustness
      work, which was relabeled to v0.6.0 (see PHASE 6).

--- v0.3.1 reliability patch ---
[x] Centralized get_severity() across secrets + LLM + DevSecOps maps
      Was defaulting every LLM/MCP/agentic and DevSecOps finding to LOW in every
      reporter (JSON/MD/XML/SARIF/HTML) and in the --severity-threshold filter
      File modified: reporter.py
[x] GitHub Action now passes --type through to the scanner
      action.yml defined a `type` input but never forwarded it (always scanned
      the default). Now: --type "${{ inputs.type }}"
[x] Exit code 2 (runtime/config/reporting error) now fails the action
      Previously a runtime error was reported as findings_detected=false and
      passed as success. Applied same policy to security.yml.
[x] Removed unsafe `|| true` from CI release-validation smoke tests
      ci.yml + package-test.yml now use an exit-code-aware wrapper
      (0/1 = pass, 2+ = fail) so genuine runtime errors fail the build
[x] Wheel-install smoke test hardened
      package-test.yml exercises JSON + SARIF + HTML from the installed wheel
      and asserts html_reporter imports; HTML reporter packaging verified
      (explicit [tool.setuptools.packages.find] added to pyproject.toml)
[x] Report metadata version corrected (get_scan_metadata: 0.2.0 -> 0.4.0)

--- v0.4.0 AI/GenAI/MCP-first repositioning ---
[x] MCP (Model Context Protocol) patterns — 4 new (llm_patterns.py)
      Unvalidated tool result in prompt, tool output executed directly,
      hardcoded MCP server URL, untrusted tool description in prompt
[x] Agentic AI patterns — 5 new (llm_patterns.py)
      Unsanitized input to agent memory, agent loop without exit condition,
      function call result not validated, recursive self-invocation risk,
      PII passed to external agent  (multiline patterns use (?is))
[x] Severities + OWASP LLM Top 10 (2025) mappings for all 9 new patterns
      (LLM_SEVERITY_MAP, owasp.py OWASP_MAP)
[x] Repositioned package/module/CLI/README/CHANGELOG around AI agents, MCP
      tools, and LLM apps; secrets + DevSecOps kept as supporting proof points
      Files: __init__.py, pyproject.toml (v0.4.0, description, keywords),
             cli.py (AI-first description + epilog), README.md, CHANGELOG.md
[x] OWASP disclaimer added (no certification/endorsement/compliance claim)
[x] Default scan type kept as `secrets` for backward compatibility
      Docs lead with `--type llm`; default change deferred to a future major
[x] Tests: 9 detections + severity + OWASP-mapping + severity-regression tests
      (test_llm_scanner.py, test_owasp.py, test_reporter.py) — 137 passing
[x] demo/ (intentionally vulnerable app) + .github/workflows/security.yml
      cherry-picked from the prior stash; security.yml hardened for exit-2

[x] Published — v0.4.0, then audit-fix releases v0.4.1 and v0.4.2, all shipped
      (see CHANGELOG.md). pyproject.toml currently at 0.4.2.

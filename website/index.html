01 / THE PROBLEM

AI code crosses boundaries ordinary request-response software often does not.

A prompt can become a tool call. Retrieved content can enter privileged context. Tool metadata can carry instructions. Model output can reach a shell, API or another consequential sink.

SecChecker statically inspects selected code shapes around those transitions before deployment.

PROMPTuser input ─────────▶ privileged context
MCPtool metadata ───────▶ agent instruction
AGENTmodel output ────────▶ consequential action
02 / SECURITY SURFACES
01

Prompt & context

Unsafe user-controlled data entering privileged prompts, delimiter manipulation and selected sensitive-context flows.

02

MCP & tool trust

Poisoned tool descriptions, untrusted metadata, tool results re-entering privileged context and selected execution boundaries.

03

Model output

Selected model- or tool-controlled values reaching eval, exec, subprocess, shell and other dangerous sinks.

04

Agent memory

User-controlled or untrusted content written directly to selected persistent-memory and vector-store patterns.

05

Agent control flow

Selected unvalidated function-call results, recursive invocation patterns and autonomous loops without clear exit conditions.

06

AI credentials

Python AST context for selected provider credentials, including how credential material is declared and passed to clients.
